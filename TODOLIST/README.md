# To-Do List App
A simple To-Do List web application
built with HTML,CSS AND JavaScript.

## Project Goal
The goal of this project is to build
a functional and user-friendly
To-Do List applucation while
Practicing front-end web development.

## Features
- Adding of Tasks
- Deleting of Tasks
- Mark tasks as completed
- Edit Tasks
- Save Tasks with localStorage
- Add task counters
- Add Alarm clock reminders
- Improve responsive design
